# 原型方法套件

| 方法 | 何时采用 | 最小产物 |
|---|---|---|
| 用户动线 | 跨页、直达、返回或角色切换 | 核对入口、路由参数、上下文恢复及异常去向，复用 PRD 的 Mermaid |
| 状态转换 | 权限、异步或多状态动作 | 记录初态、事件、前置、终态和副作用，引用既有规则与 AC |
| 固定数据走查 | 主链、异常和重复回执需要复现 | 记录场景标识、初态、事件顺序、观察点与重置方式 |
| 定向回归 | 更新既有原型 | 对照变更前后，验证受影响 AC 及直接依赖，标明旧证据的适用范围 |

使用既有 PRD 和验收记录承载这些信息，按本轮风险选择。

## 列表到详情的走查示例

以端点列表为例，准备固定的合成记录，包含启用与停用两种状态。按本轮约定筛选，打开指定记录详情，再返回并核对筛选条件及适用的分页状态。记录入口、样例业务键、动作、预期及对应验收编号。按 PRD 约定复现适用的空态、请求失败或拒绝分支，注明重置方式。详情承载或撤权规则待决时，标明相应动作及验收受阻，列表路径继续走查。示例中的行为以实际 PRD 为依据。

只修改首次进入的默认筛选时，分别核对首次进入、手动切换、重置和返回恢复。重置与返回按各自既有规则执行。
