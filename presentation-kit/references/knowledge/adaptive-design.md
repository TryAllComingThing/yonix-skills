# 专业个性化适配
先确定专业 Profile，再根据当前任务和最小有效记忆调整内容深度、叙事、术语、图解及交付要求。专业背景不等于受众背景；技术专家的领导汇报仍应聚焦决策。一次性页面反馈不等于长期偏好。品牌强制规则独立于个人视觉偏好；项目事实不可由记忆覆盖。
示例：S04+S06，15分钟，用户偏好机制深入：保留关键机制与建设风险，底层细节放附录。历史蓝白偏好遇本次绿色品牌：使用确认品牌，记录覆盖理由，不更新长期偏好。
记忆治理以 references/contracts/memory-integration.md 和共享 MEMORY.md 为准。专业反馈交给 Memory Expert，不能把 AI 建议或未执行验收当作有效经验。
