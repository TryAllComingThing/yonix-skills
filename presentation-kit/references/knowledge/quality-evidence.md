# 质量与证据
G1 检查来源、状态、范围、客户价值、专业关系；G2 检查 Locked/Required、视觉策略、模板与编辑要求；G3 检查逐页渲染、PPTX 对象、真实 PowerPoint 编辑、试讲及用户验收。状态 PASS/FAIL/NOT_VERIFIED/NA，NA 必须有理由。任何适用 P0 未通过不得正式冻结。
证据 V0 设计、V1 静态、V2 实际 Skill、V3 成品渲染、V4 PowerPoint 人工编辑。编辑 E0 整页图片、E1 图片对象、E2 矢量组合、E3 独立原生文字/形状、E4 原生表格图表或连接行为。检查对象 XML 不能代替实际编辑。
评分：真实性15、专业25、汇报20、图解10、视觉20、工程10；各维度以0–100计，目标总分90且各维度80，未验证不打分。A 原生上游、B 专业增强、C 加记忆；固定输入、模型版本、模板、时间预算，盲评并记录重复修订次数。30%下降仅候选目标。


## 可执行验收记录
每项记录检查ID、适用性、预期、实际、证据路径、状态、责任。P0：虚构事实、权威冲突、关键逻辑错误、核心遗漏、编辑性不达标、严重遮挡、文件损坏、品牌违规、越权披露、设计冒充上线。任何未验证适用P0阻止冻结。A/B/C使用独立会话、同一输入和预算，随机匿名顺序评审；记录每次修订原因与耗时，重复缺陷单独计数；至少跨项目复测，不能由单次主观评分推断持续提升。

## 集成验收
检查主辅 Profile 选择理由、记忆引用及适用条件、当前覆盖、品牌冲突、候选隔离、Brief 到上游映射、Spec Lock 一致性、真实反馈与写入授权。缺证据 NOT_VERIFIED。专项案例见集成发布包 README.md 的集成验收清单。
