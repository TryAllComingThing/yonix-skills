# Memory integration V1.4
共享根 ~/.yonix/memory/；先读 MEMORY.md，支持 V1.0/V1.1 等价记录语义。Memory Expert V1.5 推荐，读取可独立；不创建替代库。未知契约版本停止记忆操作，继续专业任务。
任务前：确定领域、受众、目标、组织和主辅 Profile。仅选相关、已确认、有效、授权记录；不读取 inbox 作为指导。输出最小上下文：记录ID/标题、适用规则、条件、例外、对当前任务影响；不复制原始画像或其他客户资料。无记忆或无权限则标记 unavailable，使用专业默认。当前明确要求覆盖普通偏好，场景优先于领域及全局；事实、安全、强制组织规范独立约束，冲突暂停相关部分。
Effective Profile 写入 Brief，包含主辅场景、内容深度、叙事、图解、相关记忆引用及影响、冲突处理、品牌引用、待确认项。不是长期记忆，不另建缓存。PMP 仅接收必要制作要求；确认后 Spec Lock 权威，变更走上游流程。品牌导入和原件编辑遵循各自路线，不强套 Generate。
任务中：反馈保留项目记录，不自动学习。任务后：将真实反馈、变更及证据交给 Memory Expert；最多三条候选，用户确认后按契约写入；无授权不持久化候选。无 Expert 则仅项目记录。禁止自行复制记忆治理逻辑。
迁移：旧版发布包或用户自行保留的历史备份仅为迁移输入（本包不携带），须用户明确授权才读取；按对象、作用域、证据归纳，候选不得自动确认。项目/客户事实留项目，品牌原件留授权资产目录；核对重复与冲突，确认后写入并重读验证。旧目录退出运行路径，不自动删除。
