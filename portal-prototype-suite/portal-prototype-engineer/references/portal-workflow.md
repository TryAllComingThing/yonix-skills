# V2 task playbooks
CREATE: classify → journey → sitemap → page contracts → visual composition → mock state machine → shared components → executable prototype → browser journeys → report.
REFERENCE: identify screenshot viewport/theme → annotate region → locate DOM/source (confidence) → propose constrained patch → verify local diff → screenshot comparison → impacted journeys/themes → report.
When both tasks appear, do not confuse a redesign with a small repair; clarify scope or record explicit design decision.
Keep the V1.4 tools for diagnostic evidence, not as the center of the task.
