# Version and configuration management
Compute SHA-256 for every input and output. Record baseline path, revision, git commit if any, dirty state, source artifact hashes, changes and test commands. If prior and latest revisions diverge, inspect diff and prepare a three-way merge; never overwrite newer work with a patch to an older file. Keep change sets atomic and preserve old release. Distinguish user-supplied source from generated candidate. Evidence package contains manifest.json, change summary and test reports. Never claim latest version without checking the available files/repository.
