# Frontend engineering expertise
Inspect package manifest, framework, lockfile, source tree, routes and component registry. Follow project's stack; for Vue 3 prefer existing SFC/composables/Pinia/TS and current UI library, not a new React stack. Search for reusable components/utilities before adding code. Use typed interfaces, stable keys, single-source state, semantic classes and scoped styles. Avoid `!important` cascades, duplicated modal templates, broad regex replacement and global mutable state when better structures exist. Preserve API contracts and event propagation. Build/test only in reproducible environment; record Node/dependency versions. For standalone HTML, isolate rendering and state transitions and document limitations. Validate computed CSS and real click behavior, not merely DOM existence.
