# UI/UX expertise
Read design-system/DESIGN.md and token files first. Establish typography hierarchy, spacing rhythm, semantic colors, borders, radius, elevation, density, icon size, motion and focus. Use one component pattern for the same behavior across pages. Evaluate information architecture, scanning order, contrast, keyboard navigation, focus restoration, labels, error messaging, localization expansion and 320/390/768/1440 responsive layouts. Prefer semantic CSS variables; hardcoded color requires documented exception. For screenshot differences classify: structural, typography, spacing, color, interaction state, asset or browser rendering. Never use visual concealment to avoid fixing an active component. For pixel tests allow explicit thresholds and manual review of legitimate antialiasing changes.
