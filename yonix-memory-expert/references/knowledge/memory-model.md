# Memory model
Five independent dimensions: cognitive type (semantic: facts/preferences; episodic: observed events; procedural: reusable methods), object (profile/fact/preference/lesson), scope (global/domain/scenario/organization/project), domain and topic, lifecycle (source, status, time, validity). A procedural preference is not proof a method works. A project decision belongs in project documents, not global memory. Organization rules require explicit organization identity and authorization; do not infer them from a customer document.
## Atomic record
One independently changeable proposition per entry; stable ID, object, cognitive type, scope, domain/scenario, statement, condition/exception, evidence source and date, status. Optional strength for preferences, outcome evidence for lessons, expiry for temporary facts. Use unknown rather than inventing values. Global scope requires explicit broad intent or confirmed cross-domain evidence. Multi-domain entries have one canonical home and optional ID references, not duplicate copies. Profile is a view of confirmed professional facts, not a personality diagnosis. Do not infer seniority from jargon or expertise from a question.
## Placement
Global profile facts in profile.md; global preferences in preferences.md; cross-domain lessons in lessons.md; domain/scenario entries in domains/<domain>.md; authorized organization rules in organizations/<safe-name>.md. Project-only facts remain in project workspace. Candidates in inbox only with permission. No raw chats, credentials, client secrets or programming habits. Unknown domain: use a topic in nearest domain, propose a new file only when sustained need exists.
## Lifecycle
Candidate -> Confirmed after authorization; confirmed -> Deprecated or replaced when explicitly superseded; deletion removes record and derived references. Deprecated never applies. Confirmation of a preference does not validate empirical claims. Source provenance distinguishes direct user statement, observed choice, user feedback, authorized document and verified result. AI suggestion alone is not user evidence.
