# Profile and preference engineering
## Five profile layers
L1 professional background: stated roles, industry, knowledge, goals; separate current skill from learning goal. L2 collaboration: delegation, review cadence, deliverables, autonomy. L3 observable decision behavior: evidence, depth, tradeoffs, risk and quality; no psychological inference. L4 domain-specific competence and needs; never transfer expertise across domains without evidence. L5 scenario: audience, task objective, deliverable, constraints. Store L1–L3 global only when supported; L4–L5 in domain files. Build a concise profile by selecting confirmed facts, not duplicating preferences. Unknown stays unknown.
## Preference taxonomy
Content, expression, structure, visual, workflow, decision, quality, delivery, learning, avoidance. Distinguish Required (explicit durable requirement), Preferred (default), Avoid (negative preference); all bounded by scope. A choice for one deck is task configuration; repeated independent choices suggest a candidate, not confirmation. Silence and assistant suggestions are not evidence. Explicit correction outranks older same-scope preference; one-off exception does not replace it. Preserve conditions and exceptions. Ask only when ambiguity changes outcome materially.
## Extraction examples
“I am learning robotics” -> learning goal, not robotics expertise. “Use blue for this deck” -> project only. “For future customer decks use blue unless branded” -> durable scoped preference if authorized. “Too shallow” -> ask or infer candidate about specific missing depth, not universal verbosity. “Never use decorative subtitles in admin pages” -> scoped Avoid, not ban all subtitles. “We use company template X” -> organization candidate, not personal taste. Repeated acceptance of assistant proposals is weaker than explicit user choice.
## Profile synthesis
Review each claim against source, scope and date. Separate factual self-description, preferences and demonstrated outcomes. If conflicting roles or skill levels, retain time/context or ask; do not average. Present candidate changes in plain language with reason and exceptions. Do not persist sensitive personal attributes or inferred psychological traits. No numeric confidence scores without calibration.
