# Using YONIX Memory Expert V1.5 (`yonix-memory-expert`)
Invoke naturally: “加载相关专业记忆”, “提取本次可复用经验”, “以后记住…”, “检查冲突”, “删除这条偏好”. No IDs required from user. Explicit invocation is recommended for important tasks; automatic activation depends on client. Professional kits should reference the shared contract, not duplicate memory. Read references/evaluation/memory-cases.md for isolated tests. Installation and migration are in package README. Methods draw on semantic/episodic/procedural memory, profile/collection approaches and long-memory evaluation concepts; no external memory engine is required.

V1.5 supports minimal context handoff to professional kits; read-only use does not require this Skill. Contract V1.1 retains record schema.
