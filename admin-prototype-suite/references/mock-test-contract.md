# Mock 与交互测试契约 V1.3

## 最小状态模型
- `entities`：稳定 ID 的唯一权威仓库；`draft`：表单隔离副本；`view`：筛选、分页、选中和弹窗状态；`snapshot`：已发布不可变副本。
- 新增：唯一性检查、字段校验、持久化至模拟仓库、列表/详情同步。
- 编辑：打开时复制，取消不提交，保存时以 ID 更新并保留引用关系。
- 删除：若被引用则拒绝，成功删除后列表和详情同步，分页边界修正。
- 发布：生成快照；后续编辑草稿不能改变已发布内容；显式再次发布才更新。
- 异常：可注入网络失败模拟、校验失败、重复提交；不模拟真实授权或真实服务成功。

## 最小浏览器断言
1. 创建对象 → 列表可见 → 详情与新值一致。
2. 编辑对象 → 取消 → 原值不变；重新编辑保存 → 新值生效。
3. 被引用对象删除 → 拒绝并说明原因。
4. 发布后编辑草稿 → 已发布快照保持原值。
5. 查询、筛选、清空、分页状态与空态正确。
6. Dialog Esc、焦点、重复点击和错误反馈可用。
7. 测试每次从确定性 seed 恢复，不受上次浏览器运行污染。

## 证据要求
- 记录 test ID、测试数据 seed、操作、期望、实际、PASS/FAIL/BLOCKED/NOT_RUN、截图或日志路径。
- 仅使用内存/浏览器本地 Mock 的演示不得称为真实后端联调。
