# Acceptance Matrix V1.2 — G0—G4

| Gate | 目标 | 必需证据 | PASS 标准 | 失败/阻塞处理 |
|---|---|---|---|---|
| G0 | 结构与构建 | 版本 SHA256、命令、日志、HTML audit/构建 | 无确定性阻断错误；风险单列 | FAIL；工具缺失 NOT_RUN/BLOCKED |
| G1 | 业务/Mock 契约 | 实体/字段/状态矩阵、正反测试 | 主链路与高风险反例正确 | 引用/发布隔离失败阻止冻结 |
| G2 | 浏览器交互 | Playwright/人工步骤、浏览器、截图/日志 | 菜单、CRUD、弹窗、Tabs、联动可用 | 浏览器不可用 BLOCKED |
| G3 | 视觉一致性 | 固定条件的前后截图、差异清单 | 无关键遮挡/溢出/重复标题 | 无截图 NOT_RUN，不得写 PASS |
| G4 | 易用性与可访问性 | 键盘/焦点/表单/危险操作走查 | 核心任务可完成且反馈清晰 | 自动工具不能代替人工 |

状态：PASS/FAIL/BLOCKED/NOT_RUN/N/A；PASS 必须有可定位证据。缺陷：P0 无法完成关键任务或数据错误，P1 核心布局/交互异常，P2 局部视觉/文案偏差。

## 管理平台最小回归集
导航与权限；列表查询/重置/分页；新增/编辑/取消/保存；删除/禁用保护；详情/编辑弹窗焦点和滚动；Tabs 三轮切换；跨页引用；同名不同 ID；发布/有效快照隔离；空态/失败/长文本；1440×900 和 1280×800 截图（按项目适配）；键盘 Tab/Enter/Esc。

## 验收决策
关键 G1/G2 FAIL 禁止发布为通过；G2—G4 未运行可交“候选版”，必须披露未验收范围。`templates/review-report.md` 填写环境、命令、结果、证据、缺陷与复测。
