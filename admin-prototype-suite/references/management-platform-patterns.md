# Management Platform Pattern Library V1.3

> 选择 Pattern 的依据是**用户任务、信息复杂度、状态风险与导航成本**，不是仅看截图外观。项目既有设计规范优先。每项 Pattern 应包含：适用/禁用、信息结构、交互、异常、视觉、验收。

| ID | Pattern | 适用场景 | 核心结构 | 不适用/取舍 | 最低验收 |
|---|---|---|---|---|---|
| P01 | 工作台/运营总览 | 快速判断态势并进入处理 | KPI、趋势、待办、异常列表 | 不堆满所有业务表格；指标必须有口径/时间 | 数据口径、点击钻取、无数据、布局 |
| P02 | 数据列表 | 查询/比较/批量处理实体 | 标题、查询、工具栏、表格、分页 | 不以大表替代复杂详情；宽度须预算 | 排序/筛选/分页/空态/溢出 |
| P03 | 查询筛选 | 缩小数据范围 | 搜索、枚举、重置、查询 | 不为少量数据强制多筛选 | 清空恢复、条件保持、空结果 |
| P04 | 只读详情 | 查看完整实体与关联 | 摘要、分组 InfoGrid、状态、关联链接 | 多步业务或需深链接用独立页 | 只读、长文本、关闭、权限 |
| P05 | 新增/编辑表单 | 配置实体与校验 | 分组字段、条件联动、错误、保存 | 多步骤且依赖强用向导 | 校验、dirty、取消、提交幂等 |
| P06 | Dialog/Drawer | 临时聚焦任务 | 单标题、滚动内容、固定操作区 | 复杂导航、需可分享 URL 用页面 | 焦点、Esc、遮罩、滚动、响应式 |
| P07 | 树形管理 | 组织/目录/层级资源 | 树、选中详情、搜索、权限 | 非层级对象不要强行树化 | 选中、展开、移动冲突、空树 |
| P08 | 配置管理 | 参数与作用范围 | 配置分组、继承/覆盖、校验、影响 | 不把运行监控混入配置 | 保存/生效分离、影响提示 |
| P09 | 权限授权 | 主体×资源×动作 | 范围选择、授权列表、撤销确认 | 不以隐藏按钮替代权限检查 | 越权、继承、撤销后可见性 |
| P10 | 监控分析 | 实时/历史态势 | 时间范围、指标、趋势、事件详情 | 不将演示数值冒充真实指标 | 时间口径、空态、状态区分 |
| P11 | 流程/状态管理 | 任务/审核/发布 | 状态、下一步动作、历史记录 | 不能仅靠标签表达业务转换 | 合法转换、拒绝、重试、审计 |
| P12 | 确认与反馈 | 高风险或不可逆操作 | 对象、影响、后果、确认/取消 | 普通保存不滥用二次确认 | 防误触、错误反馈、重复提交 |

## 决策树：详情展示
1. 需要深链接、复杂多步骤或跨模块导航？→ 独立页面。
2. 简单只读、当前上下文不可丢失？→ 居中 Dialog（优先复用既有 Dialog）。
3. 需要对照主列表、较长的编辑过程？→ 可考虑 Drawer；若项目已统一居中弹窗则遵循项目权威。
4. 详情和编辑尽量共享容器/字段显示组件，不强制同样的可编辑控件。

## 决策树：表格操作
1. 高频主操作显示文字+语义图标，图标必须与动作一致；危险操作与普通操作区分。
2. 操作数较多时计算总宽度：图标+文字+间距+内边距；优先把低频操作放入“更多”，不要让表格突破背景容器。
3. 已禁用/无权限/不适用操作需说明状态，不显示误导性可点击控件。

## 决策树：配置表单
- 字段按用户认知分组，必填与默认值明确；条件隐藏时定义是否保留旧值。
- 保存与生效分离，受影响对象先提示；校验失败保留输入并定位字段。
- 数值参数明确单位、边界、0/不限/继承语义；不凭截图推断后端默认值。

## Pattern 交付契约
每个页面规格写 `Pattern ID / 选择理由 / 备选方案及拒绝原因 / 页面结构 / 操作状态 / 空错加载态 / 数据来源 / 验收`。不同平台可以裁剪 Pattern，不得将 MaaS 特定模型/端点字段写成通用必填。

## 12 类 Pattern 的反例与风险探测

| Pattern | 常见错误决策 | 专家应主动测试的边界 |
|---|---|---|
| P01 工作台 | KPI 无口径、卡片都可点但无落地页 | 空指标、时间窗、钻取目标 |
| P02 列表 | 操作列溢出、分页删空后停在空页 | 低宽视口、长文本、最后一条删除 |
| P03 筛选 | 重置不清空、换页丢条件 | 组合筛选、空结果、URL 恢复 |
| P04 详情 | 重复标题、隐藏操作能力 | 只读保护、字段超长、关联跳转 |
| P05 表单 | 取消仍写入、隐藏字段旧值泄漏 | dirty、校验、重复提交 |
| P06 Dialog | Esc 不可用、焦点逃逸、背景滚动 | 键盘、嵌套弹窗、窄屏 |
| P07 树形 | 节点循环引用、删除父节点误删子节点 | 大树、空树、层级变更 |
| P08 配置 | 保存立即生效、覆盖继承不明确 | 继承/覆盖、非法值、发布门禁 |
| P09 授权 | 隐藏按钮代替权限、越权入口 | 角色切换、撤权、无权限空态 |
| P10 监控 | Mock 值标为实时、图表无时间口径 | 断流、时间范围、无数据 |
| P11 流程 | 任意状态可跳转、失败无回退 | 非法转换、重复执行、审计 |
| P12 确认 | 普通保存多次确认、危险操作无后果说明 | 取消、双击、不可逆提示 |

**通用验收**：每个实际选用 Pattern 在 `page-spec` 中写选择依据、状态、反例与可执行断言；未使用的 Pattern 不强行纳入页面。
